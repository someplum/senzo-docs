# Alert Rules

Admins use Alert Rules to manage the rules that raise alerts for your organization, and to review the alerts those rules have raised. Anyone else who opens the page sees an access notice.

Alert rules don't change Senzo's standard thresholds, which drive Pulse Intelligence findings, the Overview, the Burnout Risk Index and the charts. See [Thresholds and Alert Rules](/core-concepts/thresholds-and-alerts).

## Default rules

When Senzo sets up an organization, it adds four rules:

| Rule | Metric | Alert when |
|---|---|---|
| High Overtime (Warning) | Overtime % | Above 10% |
| High Overtime (Critical) | Overtime % | Above 15% |
| Elevated Sick Time (Warning) | Sick Time % | Above 5% |
| Elevated Sick Time (Critical) | Sick Time % | Above 8% |

They apply to every unit and provider type. You can edit or delete them like any other rule.

## Adding a rule

In **Threshold Rules**, click **Add Rule** and set:

- **Rule Name**
- **Metric**: NPP (Patients Per Provider), NHPPD (Hours Per Patient Day), Vacancy FTE, Overtime % or Sick Time %
- **Severity**: Info, Warning or Critical
- **Direction**: Above, Below or Outside Range, and the threshold value(s)
- **Scope**: Global (All Units), Specific Unit, Provider Type, or Unit × Provider Type

Click **Save Rule**.

## When rules run

Senzo checks every enabled rule once a day against your most recent data. An alert closes automatically when its condition clears.

## Where alerts appear

- On this page
- In Pulse Intelligence, under Active Alerts and Recent Alerts
- On the Unit Health page
- In data exports
- In the weekly digest email

# Role-Based Access Control

Senzo uses role-based access control (RBAC) to ensure users can access the features and data appropriate for their responsibilities.

## User roles

### Admin

Full platform access. Admins can:
- View all dashboards, reports, and intelligence features
- Upload and manage workforce data
- Configure settings (facilities, units, provider types)
- Manage alert rules

**Alert Rules** and **Settings** appear in the sidebar for Admins only.

Recommended for: VP Workforce, Director of HR, system administrators

### Analyst

Analysts can:
- View all dashboards, reports, and intelligence features
- Upload workforce data and edit organization configuration
- Export data and reports
- Run Pulse Intelligence

Analysts cannot manage alert rules. The **Settings** and **Alert Rules** sidebar entries are not shown to them, and opening either page directly shows an access notice. Analysts can add facilities, units and provider types by uploading an Organization Config file in **Upload Data**.

Recommended for: Workforce analysts, finance directors, CNOs who need full visibility

### Viewer

Read-only access. Viewers can view the monitoring, analysis and reporting sections — including the Overview dashboard, Pulse Intelligence, Metrics Explorer, Cost Analytics, Data Explorer and Report Builder.

Viewers cannot upload data or change configuration. **Upload Data**, **Alert Rules** and **Settings** are not shown to them, and opening any of these pages directly shows an access notice.

Recommended for: Senior executives who need a read-only view

## Managing users

Users, roles and product access are set by Senzo. Nobody in a customer organization can invite users, change roles or remove access.

Email info@senzohq.com to add someone, change a role, or revoke access. See [Inviting Your Team](/getting-started/inviting-your-team).

## Organization isolation

Users are scoped to a single organization. A user cannot access data from another organization unless Senzo also adds them to that organization.

There is no cross-organization visibility for any user role — including Admin.

## Super Admin

Super Admin is a Senzo platform-level role available only to Senzo staff. It provides visibility across all organizations for support and platform management purposes. Super Admin access is not available to customers.

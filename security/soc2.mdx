# SOC 2

## Current status

Senzo does not have a SOC 2 report yet.

## What SOC 2 means

SOC 2 is a third-party audit of a company's security, availability, and data handling practices against the AICPA Trust Services Criteria. A SOC 2 report provides assurance to customers that controls are in place and operating effectively.

- **Type I** — confirms controls are designed correctly at a point in time
- **Type II** — confirms controls operated effectively over a 6–12 month period

Enterprise procurement teams at health systems typically require SOC 2 Type II before approving a vendor.

## Controls in place today

**Access control**
- Sign-in through Supabase Auth, with passwords of at least 12 characters
- Role-based access (Admin, Analyst, Viewer)
- Row Level Security enforced in the database
- Super Admin access checked on the server

**Data protection**
- Encryption in transit (HTTPS/TLS)
- Encryption at rest (AES-256, by Supabase)
- Each customer organization's data is kept separate from other customers' data (see [Data Handling](/security/data-handling))

**Security contact**
- Report security issues to info@senzohq.com

**Service providers**
- Supabase (database and sign-in; AWS ca-central-1, Montréal) — SOC 2 Type II report
- Vercel (application servers; Washington, D.C.) — SOC 2 Type II attestation
- Anthropic (Claude API) — its Commercial Terms do not allow it to train models on Senzo customers' data
- Resend (weekly digest email)

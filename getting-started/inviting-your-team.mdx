# Inviting Your Team

Senzo supports role-based access control so different team members see the right level of data for their role.

## User roles

| Role | Access level |
|---|---|
| **Admin** | Everything an Analyst can do, plus Alert Rules and Settings |
| **Analyst** | Views every monitoring, analysis and reporting section; can upload data and edit organization configuration |
| **Viewer** | Read-only — views the monitoring, analysis and reporting sections, but cannot upload data or change configuration |

Viewers do not see **Configure → Upload Data** in the sidebar; opening the upload page directly shows an access notice instead of the wizard. **Alert Rules** and **Settings** appear in the sidebar for Admins only. Anyone else who opens Settings directly sees an access notice; on Alert Rules they see the alerts, but not the rule editor.

## Getting an account set up

Senzo sets up accounts. Email info@senzohq.com with each person's name, email address and role.

Each person then gets an email from Senzo with a link to set a password. The password must be at least 12 characters. The link works once and expires after 24 hours; if it expires, ask Senzo to resend it.

Someone who has already set a password and forgotten it uses **Forgot password?** on the sign-in page.

<Note>
  The link signs in as the address it was sent to. Don't forward it — whoever opens it can set the password for that account.
</Note>

## Changing a role

To change someone's role, email info@senzohq.com.

## What new users see

After setting a password, someone with access to one Senzo product goes straight into it. Anyone with more than one product, in one organization or across several, picks one on the product selection page. If data has already been uploaded, the Overview dashboard is populated as soon as they open it.

<Tip>
  Brief your team before they log in for the first time. Walking them through the Overview and Pulse Intelligence sections in a short 15-minute session will dramatically reduce the time to first value.
</Tip>
